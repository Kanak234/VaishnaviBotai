# VaishnaviBot

A bot project. The actual bot, its changelog and configuration live in
[`VaishnaviBot/`](VaishnaviBot/); a `.env.example` there lists the environment
variables it expects (copy it to `.env` and fill in your own values — never
commit real secrets).

## Status

See [`VaishnaviBot/CHANGELOG.md`](VaishnaviBot/CHANGELOG.md) for what works.
Configuration is required before running; the real credentials are not part of
this repository.
